Boucler la boucle de jeu (priorité haute)
Sans ça, santé / shield / repair restent des démos.

Dégâts entrants sur le joueur
Obus ennemis (ou zones de test) qui appellent takeDamage(). Aujourd’hui rien ne baisse la vie en combat réel.

Mort + fin de partie
HP à 0 → arrêt du tank (ou écran Game Over / retour menu). Le HUD santé devient alors utile au-delà du test repair.

Ennemis simples
Un ou deux tanks statiques ou qui patrouillent, tirent lentement, COL_* + même système de projectiles. C’est le plus gros morceau, mais ça valide tout le reste.

Gameplay / ressources (rapide à moyen)
weapon_boost — config déjà là (damageMultiplier, stacks) : brancher le pickup + effet sur obus/balle.

Pause / restart

HUD
